# Support · Dukungan

**EN** — Need help with a CoreTrees project? Here's how to get it.<br/>
**ID** — Butuh bantuan untuk proyek CoreTrees? Berikut caranya.

## Before you ask · Sebelum bertanya

**1.** Read the repository's **README** and any files in `docs/`. · Baca **README** repositori dan berkas di `docs/`.<br/>
**2.** Search existing **Issues** and **Discussions** — your question may be answered. · Cari di **Issues** & **Discussions**.

## How to get help · Cara mendapatkan bantuan

| I want to… · Saya ingin… | Use · Gunakan |
|---|---|
| Ask a question / discuss an idea · Bertanya / berdiskusi | **GitHub Discussions** (Q&A) |
| Report a reproducible bug · Melaporkan bug | **Issues** → *Bug report* template |
| Request a feature · Mengusulkan fitur | **Issues** → *Feature request* template |
| Report a security issue · Melaporkan isu keamanan | See [SECURITY.md](./SECURITY.md) — **not** a public issue |

## Writing a good request · Menulis permintaan yang baik

Include · Sertakan: what you expected, what happened, steps to reproduce, versions, and logs or screenshots. · Yang diharapkan, yang terjadi, langkah reproduksi, versi, serta log/tangkapan layar.

## Response expectations · Ekspektasi respons

**EN** — CoreTrees is maintained on a best-effort basis. We aim to respond to issues and discussions promptly, but response times may vary. Clear, reproducible reports get resolved fastest.<br/>
**ID** — CoreTrees dikelola secara *best-effort*. Kami berupaya merespons secepat mungkin, namun waktu respons dapat bervariasi. Laporan yang jelas dan dapat direproduksi ditangani paling cepat.
