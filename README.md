# `.github` — CoreTrees community & organization defaults

**EN** — This special repository powers the CoreTrees **organization profile** and provides **default community health files** and **starter workflows** inherited by every repository that doesn't define its own.<br/>
**ID** — Repositori khusus ini menggerakkan **profil organisasi** CoreTrees serta menyediakan **community health files default** dan **starter workflow** yang diwarisi oleh setiap repositori yang belum memilikinya sendiri.

---

## What's inside · Isi repositori

| Path | Purpose · Fungsi |
|---|---|
| `profile/README.md` | Shown on the org page · Tampil di halaman org (github.com/CoreTrees) |
| `profile/assets/` | Banner and brand images · Aset banner & merek |
| `ISSUE_TEMPLATE/` | `config.yml`, `bug_report.yml`, `feature_request.yml` |
| `workflow-templates/` | Org-wide starter CI workflows (Node/TS, Go) · Starter workflow CI |
| `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SECURITY.md`, `SUPPORT.md`, `GOVERNANCE.md` | Community health files |
| `CODEOWNERS`, `FUNDING.yml`, `PULL_REQUEST_TEMPLATE.md` | Review routing, sponsorship, PR template |

---

## How defaults work · Cara kerja default

**EN** — GitHub automatically applies the files above to any CoreTrees repository that does **not** contain its own version. To override for a specific repo, add the same file there.<br/>
**ID** — GitHub otomatis menerapkan berkas di atas ke repositori CoreTrees mana pun yang **belum** memiliki versinya sendiri. Untuk menimpa pada repo tertentu, tambahkan berkas yang sama di repo itu.

## Editing the profile · Menyunting profil

Edit `profile/README.md`. Images use absolute `raw.githubusercontent.com` URLs pinned to the `main` branch — if the default branch is renamed, update those URLs.<br/>
Gambar memakai URL `raw.githubusercontent.com` absolut yang menunjuk branch `main`; bila nama default branch diganti, perbarui URL tersebut.
